Question:
I would like you to reverse engineer a gate-level netlist back to its original RTL description.
The netlist was synthesized from a Verilog RTL design.

Please create an equivalent, clean, and readable RTL description that implements the same functionality.
Your RTL should be written in standard Verilog or SystemVerilog using best practices.

The module should be named 'TopModule' with the following interface:
input [2:0] in, output [1:0] out

Gate-level netlist:
```verilog
module RefModule(in, out);
  wire _0_;
  wire _1_;
  wire _2_;
  input [2:0] in;
  output [1:0] out;
  assign _0_ = ~in[1];
  assign _1_ = ~(in[0] & in[2]);
  assign _2_ = ~(in[0] ^ in[2]);
  assign out[0] = ~(in[1] ^ _2_);
  assign out[1] = ~((_0_ | _2_) & _1_);
endmodule
```

Answer:
[BEGIN]
module TopModule(
  input [2:0] in,
  output [1:0] out
);
  // This module counts the number of 1's in the 3-bit input vector
  // and outputs the count as a 2-bit binary number (0-3)
  // This is also known as a population count or hamming weight
  
  // Using clean, readable Verilog with direct assignments
  assign out[0] = in[0] ^ in[1] ^ in[2]; // LSB of count is 1 if odd number of 1's
  assign out[1] = (in[0] & in[1]) | (in[1] & in[2]) | (in[0] & in[2]); // MSB is 1 if ≥2 bits are 1
  
  // Alternative implementation using + operator (which counts bits)
  // assign out = in[0] + in[1] + in[2];
endmodule

The netlist was synthesized from a Verilog RTL design.

Your RTL should be written in standard Verilog or SystemVerilog using best practices.

The module should be named 'TopModule' with the following interface:
input [99:0] a, input [99:0] b, input sel, output [99:0] out

Gate-level netlist:
```verilog
module RefModule(a, b, sel, out);
  input [99:0] a;
  input [99:0] b;
  output [99:0] out;
  input sel;
  assign out[54] = sel ? b[54] : a[54];
  assign out[55] = sel ? b[55] : a[55];
  assign out[56] = sel ? b[56] : a[56];
  assign out[57] = sel ? b[57] : a[57];
  assign out[58] = sel ? b[58] : a[58];
  assign out[59] = sel ? b[59] : a[59];
  // ... many more individual bit assignments ...
  assign out[0] = sel ? b[0] : a[0];
  assign out[1] = sel ? b[1] : a[1];
  assign out[2] = sel ? b[2] : a[2];
  // ... and so on for all 100 bits ...
endmodule
```

Answer:
[BEGIN]
module TopModule(
  input [99:0] a,
  input [99:0] b,
  input sel,
  output [99:0] out
);
  // This module implements a 100-bit wide 2-to-1 multiplexer
  // When sel is 0, output equals input a
  // When sel is 1, output equals input b
  
  // The synthesized netlist assigns each bit individually,
  // but in RTL we can use a much cleaner vector-wide assignment
  assign out = sel ? b : a;
endmodule
